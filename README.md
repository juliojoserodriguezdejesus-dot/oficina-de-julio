# Oficinas de Julio

Mi oficina de agentes.

- **Oficina 3D (estilo LEGO):** https://claude.ai/artifact/G78cQyyqqUxTYZ3hyHD5qB (código en `oficina/oficina.html`). Campus con un Núcleo de Dirección y un departamento por agente. El jefe llama a reunión, reparte la tarea, contrata especialistas si faltan; los agentes caminan, trabajan en su escritorio y puedes chatear con cada uno. Dashboard con indicadores, flujo de trabajo y directorio.
- **Agentes para Claude Code** en `.claude/agents/`: `director`, `asesor-de-consumo`, `trabajador-economico`, `auditor-de-sesion`. Copia esa carpeta a cualquier proyecto (o a `~/.claude/agents/`) para usarlos.
