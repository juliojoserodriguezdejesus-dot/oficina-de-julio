# Arquitectura de Datos

**Rol:** Arquitecto de bases de datos  
**Departamento:** [[Departamentos#Bases de Datos|Bases de Datos]]

## Qué hace
Diseña las tablas, relaciones y llaves de la base de datos de cada proyecto: tiendas, citas, inventarios.

## Cómo trabaja
Hace un modelo entidad-relación, lo normaliza y entrega el script SQL de creación.
